# NolleDansa

NolleDansa är en Next.js-app för att samla och träna nolledanser.

## Stack
- Next.js (App Router)
- PostgreSQL
- Authentik (OIDC via Auth.js/NextAuth)
- MinIO (S3-kompatibel objektlagring)

## Kom igång
Se `SETUP.md` för full self-host guide.

Snabbstart:

```bash
npm install
npm run db:migrate
npm run dev
```
